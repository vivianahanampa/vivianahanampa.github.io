# vivianahanampa.github.io

Personal site — CV, projects, and everything else.

Plain HTML and CSS, no build step. `index.html` is the whole site; images live
in `assets/` (see `assets/README.md` for the filenames it expects).

Served at https://vivianahanampa.github.io

## Editing

Open `index.html` and edit the text directly. The sections are, in order:
hero, About, Curriculum vitae, Projects, Speaking & advocacy, Photography,
Contact.

Anything still needing input is marked with a `.fill` span or a dashed
`data-slot` link, both visually obvious in the rendered page.
