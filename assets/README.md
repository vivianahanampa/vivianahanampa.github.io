# Image assets

Drop the files below into this folder using **exactly these names**. The page
falls back to `.jpg` automatically if a `.png` is missing, so either extension
works. Any image that is absent renders as a labelled placeholder, so the site
never looks broken while it is being filled in.

| Filename | Where it appears |
|---|---|
| `1-me-in-the-library.png` | Hero portrait (top of the page) |
| `2-me-giving-a-talk.jpg` | Speaking & advocacy (portrait, cropped to 3:4) |
| `photo-1.png` | Photography — wide, first in the grid |
| `photo-2.png` | Photography |
| `photo-3.png` | Photography |
| `photo-4.png` | Photography |
| `maya-nyc.png` | Maya and me in New York |
| `Viviana_Hanampa_Resume.pdf` | Contact "Download CV" link, hidden until a resume without GPA is added |

Keep images under ~500 KB each — export at roughly 1600 px on the long edge.
The hero portrait is cropped to 4:5, the grid tiles to 1:1, and the wide tile
to 2:1, so allow a little margin around the subject.
